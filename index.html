STEP 1

競艇場を選択

競艇場の特徴
競艇場を選択すると、特徴とおすすめ出目を表示します。
STEP 2

6艇の入力データ

🚤 RACE DATA / 6 BOATS

展示タイムは17.00～22.00を0.10刻み。過去10走は1着数・着内数、階級、今節の調子、実際の出走コースを入力してください。

STEP 3

最終の入力データ

横スクロールなしで、6艇を縦に並べて表示します。出走コース・階級は選択した内容をそのまま表示します。

「入力データを反映」を押すと6艇分を表示します。
STEP 4

10回シミュレーション

入力データを使って、競艇を基準に3周走った想定で10レースをランダムシミュレーションします。展示タイムは約半周タイムとして扱い、出走コース・階級・調子のポイントが高い艇ほど有利になるようにしています。風・波の影響も反映します。可視化は行わず、結果のみ表示します。

🏁 3 LAPS / 10 RACES
「10回シミュレーションする」を押してください。
ADVICE

アドバイスポイント

追い風時 → スロー有利
向かい風時 → ダッシュ有利
左横風時 → スロー有利
右横風時 → ダッシュ有利
上げ潮時 → センター・アウト有利
下げ潮時 → イン有利
気温低い時 → 直線タイムが良い人有利
POINT

ポイントルール

展示タイム：6艇の数値を小さい順に 3 / 2.5 / 2 / 1.5 / 1 / 0 点
過去10走：1着数6以上＝3点、着内数6以上＝1.5点
階級：A1＝3点、A2＝2点、B1＝1点、B2＝0点
調子：1＝3、2＝2.5、3＝2、4＝1.5、5＝1、6＝0.5点
実際の出走コース：1コース＝3点、2～4コース＝2点、5～6コース＝1点
